LOONOOL · Logo 风险检测工具 Demo

这是一个演示项目首页。可以从这里进入「报告详情页」和「PDF 报告模板」页面。

打开报告详情页面（Web） 打开 PDF 报告模板（report.pdf.html）

报告详情页面（report.html）

用于展示 Safe-to-Use 报告的 Web 页面结构，包含：

  • Logo 预览区域
  • 综合评分（A–E）
  • 四大检测模块卡片
  • 综合建议 & 风险声明

前端可以在这个页面接入真实接口数据。

PDF 报告模板（report.pdf.html）

用于 HTML → PDF 的模板，包含：

  • A4 排版、适合打印
  • 和 Web 报告一致的模块顺序
  • 适合作为导出给客户的正式报告

通常由后端或前端脚本渲染并导出为 PDF 文件。
